Client delivery — Japanese healthcare SaaS

Agentic RAG clinic assistant

An assistant that lets clinic staff query patient records, appointments, and clinical guidelines in natural Japanese, replacing multi-screen manual lookup. I moved the system from a fixed LLM-router pipeline to autonomous agent tool selection across five tools, based on a structured eight-point architecture comparison. Retrieval combines dense embeddings and BM25 through Reciprocal Rank Fusion, with Japanese morphological analysis to recover domain terminology that dense retrieval alone missed.

Dual guardrails protect patient data: SELECT-only SQL validation plus output inspection, with SSE streaming responses and source attribution.

LLM evaluation for an AI voice system

An automated test harness in which an AI agent places live phone calls, role-plays patients in Japanese, and grades the transcripts against expected outcomes using LLM-as-a-Judge. It cut manual regression-testing effort by roughly 80%, turning a non-reproducible manual process into a repeatable pipeline.

Per-call API cost is calculated automatically from token usage, and non-engineers can author test cases through a spreadsheet interface.

LLM product recommendation engine

A cold-start problem with no purchase history. I tested and rejected two approaches on measured evidence: vector pre-filtering converged to 81–83% similarity across the catalog, and lightweight-model filtering degenerated to list order. The delivered design is a single-pass full-catalog LLM architecture that generates product selections, rationale, and patient-facing copy at approximately ¥1.2 per recommendation and 1.9–13.0 s latency.

I also identified the roughly 150-item catalog size at which a two-stage architecture becomes cost-justified.

Appointment recommendation system

I analyzed patient visit histories in pandas before committing to a build. Free-text treatment names turned out to be the accuracy ceiling, at 85–90% keyword-match recovery, so I recommended a mandatory-category schema change to the client's backend rather than building on unreliable data.

The design pairs collaborative filtering with a sequence model, using transition-matrix analysis to disprove a naive last-treatment heuristic, and a priority gate withholds recommendations for patients without sufficient history.

Bilingual RAG chatbot over 450+ company pages

A Japanese and English chatbot built over the company's public websites, covering more than 450 pages across the group companies. Multilingual embeddings with FAISS, plus hybrid vector and keyword re-ranking that fixed a cross-lingual retrieval failure. A FastAPI backend supports swappable hosted and local LLM providers, answers are source-cited, and the whole thing ships as an embeddable web widget.

Reviewed with management, who requested follow-on features.
