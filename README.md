# Nafis Iqbal portfolio

Source for the public portfolio at [nafis2675.github.io/portfolio/Portfolio/](https://nafis2675.github.io/portfolio/Portfolio/).

The site is plain HTML, CSS, and JavaScript in `Portfolio/`. Open `Portfolio/index.html` through a local static server to preview it:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/Portfolio/`. The English and Japanese toggle is implemented with `data-en` and `data-jp` attributes.

Client work is described at a high level. Do not add client data, internal code, or demo links without approval. Keep role dates, outcomes, contact links, and project claims aligned with the current resume.
